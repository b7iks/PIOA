# Прототип Базы Данных (Студенты) — Файловые СУБД

Учебный проект по дисциплине «Программирование и основы алгоритмизации». В рамках выполнения задания 4 архитектура расширена поддержкой постоянного хранения данных на диске (JSON/CSV) с сохранением полиморфного интерфейса доступа.

## 📂 Структура проекта

Проект организован по стандарту src-layout:

```text
PIOA-123BV-25/
├── src/
│   └── db/
│       ├── backend/
│       │   ├── __init__.py
│       │   └── memory.py      # Класс StudentDatabase с гибким механизмом индексов
│       ├── __main__.py        # Конфигурация запуска СУБД
│       └── tui.py             # Класс StudentTUI с защитой ввода
├── tests/
│   └── test_db.py             # Вынесенные автотесты модулей (pytest)
├── README.md                  # Исправленная документация
└── .gitignore                 # Исключение локальных артефактов

```

## 🛠 Реализованные хранилища (Task 4)

1.  **In-Memory СУБД (`StudentDatabase`)**: Хранит данные в оперативной памяти. Быстрая, но данные стираются при перезапуске.
2.  **Файловая JSON СУБД (`JsonStudentDatabase`)**: Хранит структуру таблицы и записи в текстовом файле `students.json`. Осуществляет автоматическую сериализацию/десериализацию типов.
3.  **Файловая CSV СУБД (`CsvStudentDatabase`)**: Дополнительное текстовое хранилище в формате табличных строк `students.csv` с явным приведением типов при чтении.

Все классы СУБД унаследованы от единого предка и сохраняют полную совместимость публичных методов (`create_record`, `select_record`, `sort_records`).

## 🚀 Инструкция по работе

### Запуск приложения
При запуске программа предложит выбрать режим работы хранилища:
```bash
export PYTHONPATH=\$PYTHONPATH:./src && python3 -m db
```

### Запуск тестов и аудит покрытия
Проверка стабильности файловых операций и уровня покрытия кода:
```bash
export PYTHONPATH=\$PYTHONPATH:./src && python3 -m pytest --cov=db
```
