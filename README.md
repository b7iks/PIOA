# PIOA 123bv-25
# Прототип In-Memory Базы Данных (Студенты) — ООП Рефакторинг

Учебный проект по дисциплине «Программирование и основы алгоритмизации». В рамках выполнения задания **Task 3** система управления данными была переработана с использованием объектно-ориентированного подхода (ООП) и покрыта автоматизированными тестами.

## 📂 Структура проекта

Проект организован по стандарту **src-layout** для четкого разделения логики, интерфейса и тестов:

```text
PIOA-123BV-25/
├── src/
│   └── db/
│       ├── backend/
│       │   ├── __init__.py
│       │   └── memory.py      # Класс StudentDatabase: логика БД и инкапсуляция данных
│       ├── __init__.py
│       ├── __main__.py        # Точка входа: инициализация объектов и запуск
│       └── tui.py             # Класс StudentTUI: консольный интерфейс пользователя
├── tests/                     # Набор автоматизированных тестов (pytest)
├── README.md                  # Документация проекта
└── .gitignore                 # Исключение временных и системных файлов
 
 Реализованные изменения (Task 3)
Объектно-ориентированная архитектура

Инкапсуляция: Вся работа с данными (CRUD) перенесена в методы класса StudentDatabase. Прямой доступ к хранилищу извне ограничен.
Разделение ответственности: Пользовательский интерфейс выделен в класс StudentTUI, который взаимодействует с базой данных через внедрение зависимостей (DI).
Управление состоянием: Данные теперь хранятся внутри экземпляра класса.

Тестирование и надежность

Проект покрыт тестами с использованием фреймворка pytest.
Покрытие кода (Coverage): 100% для ключевых модулей бизнес-логики (backend/memory.py).
Реализованы тесты на позитивные сценарии (создание, фильтрация) и негативные (валидация ID, проверка возраста).

Инструкция по работе

Требования
Python версии 3.12+
Библиотеки для тестирования: pytest, pytest-cov

Запуск приложения

Выполните команду из корневой директории:

export PYTHONPATH=$PYTHONPATH:./src && python3 -m db

Запуск тестов и аудит покрытия
Для проверки выполнения требований по покрытию (>80%):
export PYTHONPATH=$PYTHONPATH:./src && python3 -m pytest --cov=db

Технические стандарты
Type Hinting: Полная аннотация типов для методов и атрибутов классов.
Clean Code: Соблюдение принципов единственной ответственности и стандартов PEP 8.
